블로그를 열었습니다.

당장 무엇을 쓸지 정해두진 않았지만, 일단 기술 블로그에 가까운 형태로 시작합니다. Zola + Tabi + Cloudflare Pages 조합이고, 도메인은 `wonjin.xyz` 입니다.

## 왜 새 블로그?

- **기록**: 배운 것/삽질한 것을 흘려보내지 않기
- **정리**: 글로 풀어 쓰면 이해가 더 단단해지므로
- **공유**: 누군가에게 도움이 되면 좋음

## 운영 방침

- 짧아도 좋다. 완벽하게 쓰려다 안 쓰는 것보다 낫다.
- 코드 블록은 자유롭게 — 한국어 본문에 영문 코드가 섞이는 게 자연스러움.
- 댓글은 GitHub 계정 기반(Giscus)으로 받습니다.
